Overview
MotorMatch is a prototype vehicle listings platform developed as part of our course project. This MVP demonstrates core features such as browsing listings, viewing vehicle details, and basic admin functionality.

How to Run
Clone the repository: git clone [PASTE REPO LINK]

Open the project in your IDE.

Run the main application file.

Features Implemented
Browse vehicle listings
View vehicle details
Basic admin functionality
Prototype user interface
Notes
This is an MVP for Iteration 1, so some advanced features are not yet implemented.
